# 📐 Arithmetic Arranger

![Status](https://img.shields.io/badge/Projeto-Concluído-green)
![Python](https://img.shields.io/badge/Python-3.x-blue)
![License](https://img.shields.io/badge/Licença-MIT-brightgreen)

Projeto em Python que organiza expressões aritméticas em formato vertical, semelhante ao método tradicional de fazer contas à mão. O usuário insere as expressões e escolhe se quer exibir ou não os resultados.

---

## ✨ Funcionalidades

- Formata até 5 expressões aritméticas por vez
- Aceita apenas adição e subtração
- Valida erros comuns (mais de 4 dígitos, operadores inválidos, etc.)
- Permite ocultar ou mostrar os resultados

---

## 🧪 Exemplo de uso

Entrada do usuário:

- Digite os problemas separados por vírgula (exemplo: 8+2, 45-10, 99+1)
- Deseja mostrar as respostas? (s/n): s
